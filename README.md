## About

Backend Engineer with **4 years** of experience designing and delivering **Java / Spring Boot microservices** and versioned REST APIs across the full backend lifecycle — API design, data modeling, caching, asynchronous processing, security, and deployment.

I work on **event-driven, high-availability systems** and care about the parts users feel: latency, reliability, and clean, maintainable code. My current focus spans **Spring Cloud microservices, Kafka pipelines, Redis/Elasticsearch/Cassandra performance, and enterprise security (JWT, RBAC, mTLS, SAML SSO)**. I'm also exploring **AI-augmented engineering** with the Claude Agent SDK and Model Context Protocol (MCP).

- Designing layered Spring Boot services — **Controller → Service → Repository**, DTO boundaries, centralized error handling
- Building **Kafka producers/consumers** for cross-datacenter state propagation, with retries and idempotency
- Optimizing **query latency and repeat reads** with JPA tuning, indexing, and Redis caching
- Hardening APIs with **OAuth2/JWT, RBAC, mTLS**, and secure service-to-service communication
